## Laboratorio Educativo de Agentes IA Autónomos + Hardware IoT

**Para escuelas, ministerios de educación y ONGs tecnológicas.**

> "Los estudiantes no solo aprenden a programar;
> aprenden a construir sistemas que piensan,
> sienten y actúan de forma soberana."

---

# 🎯 ¿Qué es este proyecto?

HormigasAIS Edu Lab es un laboratorio educativo construido para enseñar:

- Inteligencia Artificial
- Edge Computing
- IoT
- Protocolos soberanos
- Programación Python
- ESP8266
- Sistemas Multi-Agente

Todo utilizando hardware económico y software libre.

---

# 🧠 Arquitectura
